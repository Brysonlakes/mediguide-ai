# MediGuide AI

A visually polished educational symptom-assistant prototype built with React and Vite.

## Important
This is not a diagnostic or prescribing system and is not ready for clinical or public deployment. Treatment content must be reviewed and version-controlled by qualified clinicians and pharmacists. Regulatory, privacy, security, quality-management, usability, and clinical-validation work is required before licensing or reliance.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Current demo capabilities
- Responsive light/dark interface
- Symptom text entry
- Basic emergency phrase detection
- Educational condition examples
- Treatment goals, options, and explanations
- Escalation guidance

## Not included
- Real AI backend
- Diagnosis or prescribing
- Patient accounts or health-data storage
- Clinical validation or regulatory approval
